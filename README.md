## ✨ Features

- **🎹 Tonart-Dropdown** – Wähle die klingende Tonart deines YouTube-Backing-Tracks (alle 12 Tonarten, Dur & Moll).
- **🔄 Automatische Transposition** – Berechnet +1 Ganzton höher für B♭-Flügelhorn – sofort sichtbar.
- **🎼 3 Skalen-Typen** – Moll-Pentatonik, Blues-Skala und Dur-Skala als umschaltbare Tabs.
- **🎺 Noten-Karten mit Ventilanzeige** – Jede Skalen-Note als große Karte mit grafischer 3-Ventil-Anzeige (gedrückte Ventile leuchten).
- **📋 Ventiltabelle** – Vollständige Referenz aller 12 Töne mit Griffweisen.
- **🌍 Tonarten-Übersicht** – Alle Tonarten auf einen Blick mit Pentatonik-Noten und Ventilen.
- **📱 Responsive Design** – Dunkles Theme, optimiert für Desktop & Smartphone.

## 📖 Anleitung

### 1. Tonart wählen

Wähle im Dropdown die **klingende Tonart** deines Backing-Tracks (z. B. *C-Dur / A-Moll*).

### 2. Transposition ansehen

Direkt darunter siehst du die **transponierte Tonart** für dein B♭-Flügelhorn (+1 Ganzton höher).

> **Beispiel:** C-Dur → D-Dur · A-Moll → H-Moll

### 3. Skala auswählen

Klicke auf einen der Skalen-Tabs:

| Tab | Beschreibung |
|-----|-------------|
| **Moll-Pentatonik** | 5 Töne – ideal für Blues & Rock-Solos |
| **Blues-Skala** | 6 Töne – Moll-Pentatonik + verminderte Quinte (b5) |
| **Dur-Skala** | 7 Töne – vollständige Dur-Skala |

### 4. Noten & Griffe ablesen

Jede Note wird als Karte angezeigt mit:

- **Notenname** (deutsche Notennamen: H, B, Es …)
- **Skalengrad** (Grundton, kleine Terz, Quarte …)
- **Grafische Ventilanzeige** – leuchtende Kreise = gedrückte Ventile
- **Ventil-Kombination** als Text (z. B. `1-2`, `2-3`, `0`)

### 5. Übersicht nutzen

Unten findest du eine **Übersicht aller Tonarten** – klicke auf eine Karte, um direkt zur entsprechenden Tonart zu springen.

## 🏗️ Technik

- **Single-File** – Alles in einer `index.html` (HTML + CSS + JS, keine externen Abhängigkeiten).
- **Zero Dependencies** – Kein Framework, kein Build-Step, kein Server nötig.
- **Responsive** – CSS Grid + Flexbox, Media Queries für Mobilgeräte.
- **Dark Theme** – Angenehm für den Einsatz unter Bühnenlicht.
